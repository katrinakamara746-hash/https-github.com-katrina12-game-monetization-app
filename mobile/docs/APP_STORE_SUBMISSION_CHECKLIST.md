# App Store Submission Checklist

## Pre-Submission

- [ ] Read Apple App Store Review Guidelines
- [ ] Read Google Play Developer Policy Center
- [ ] Set app version to 1.0.0
- [ ] Update app name and description
- [ ] Prepare 4-5 high-quality screenshots (each platform)
- [ ] Create app preview video (iOS)
- [ ] Write compelling app description
- [ ] Set app category and age rating
- [ ] Prepare keywords (5-7 max per store)
- [ ] Create app icon (1024x1024 PNG)
- [ ] Ensure all privacy policy links work
- [ ] Ensure all terms of service links work
- [ ] Configure push notifications settings
- [ ] Test app thoroughly on real devices
- [ ] Ensure app crashes are fixed
- [ ] Test all in-app purchase flows
- [ ] Verify payment processing
- [ ] Check battery usage and performance
- [ ] Test on various device sizes
- [ ] Verify accessibility compliance
- [ ] Test with different network speeds

## iOS (App Store)

### Account Setup
- [ ] Register Apple Developer Program ($99/year)
- [ ] Complete Apple Developer Agreement
- [ ] Set up App Store Connect account
- [ ] Add team members if needed
- [ ] Configure bundle identifier (com.gamemonetization.app)
- [ ] Register development certificates
- [ ] Create App Store provisioning profile
- [ ] Register test devices (if needed)
- [ ] Create test user accounts

### App Configuration
- [ ] Create new app in App Store Connect
- [ ] Set app name and subtitle
- [ ] Add primary category and secondary category
- [ ] Set content rating (complete questionnaire)
- [ ] Configure age rating
- [ ] Set pricing and availability
- [ ] Add privacy policy URL
- [ ] Add support URL
- [ ] Configure in-app purchases
- [ ] Set up App Analytics

### Build & Upload
- [ ] Build app for release (archive)
- [ ] Sign with distribution certificate
- [ ] Create app bundle or IPA file
- [ ] Validate with App Store
- [ ] Upload to App Store Connect
- [ ] Fill in "What's New in This Version"
- [ ] Submit for review

### Post-Submission
- [ ] Monitor App Store Connect for review status
- [ ] Respond to review feedback within 24 hours
- [ ] Address any rejection issues
- [ ] Resubmit if rejected
- [ ] Monitor app after launch
- [ ] Update app regularly

## Android (Google Play)

### Account Setup
- [ ] Register Google Play Developer Account ($25 one-time)
- [ ] Complete payment setup
- [ ] Add team members if needed
- [ ] Configure bundle name (com.gamemonetization.app)
- [ ] Generate signed APK/AAB
- [ ] Create signing key and keystore

### App Configuration
- [ ] Create new app in Google Play Console
- [ ] Fill in app title and short description
- [ ] Add full description
- [ ] Set app category
- [ ] Set content rating (complete questionnaire)
- [ ] Configure age rating
- [ ] Set privacy policy URL
- [ ] Configure in-app products
- [ ] Set pricing and availability
- [ ] Add target countries/regions

### Build & Upload
- [ ] Build release APK/AAB
- [ ] Sign with key store
- [ ] Test signed build on device
- [ ] Upload to internal testing track first
- [ ] Test with beta users
- [ ] Upload to production
- [ ] Fill in "What's New in This Version"
- [ ] Submit for review

### Post-Submission
- [ ] Wait for automatic review (usually 1-3 hours)
- [ ] Monitor Google Play Console for issues
- [ ] Respond to user reviews
- [ ] Update app regularly
- [ ] Monitor crash reports
- [ ] Check ANR (Application Not Responding) reports

## Critical Compliance

### Privacy & Security
- [ ] Privacy Policy covers all data collection
- [ ] GDPR compliant (if targeting EU)
- [ ] CCPA compliant (if targeting California)
- [ ] Secure API endpoints (HTTPS only)
- [ ] No hardcoded credentials
- [ ] Secure storage of auth tokens
- [ ] Encryption of sensitive data

### Payment
- [ ] Use app store for all payments (Apple/Google)
- [ ] Display pricing clearly
- [ ] Respect refund policies
- [ ] No circumventing payment systems
- [ ] Proper handling of failed transactions

### Content
- [ ] No hate speech or discrimination
- [ ] No explicit content
- [ ] No gambling (unless properly declared)
- [ ] No copyright infringement
- [ ] Proper attribution of images/content

### Performance
- [ ] App launches in < 3 seconds
- [ ] No crashes during testing
- [ ] Proper memory management
- [ ] Handles network failures gracefully
- [ ] Works offline where applicable

## Screenshots & Marketing

### Required for iOS
- 5 screenshots at 1242 x 2688 (6.5" display)
- Alternative: 1170 x 2532 (6.1" display)
- App preview video (up to 30 seconds)
- App icon (1024 x 1024)
- Preview image (up to 1600 x 900)

### Required for Android
- 4-8 phone screenshots (1080 x 1920 or 9:16 ratio)
- Optional: 7" tablet screenshots (1200 x 1920)
- Optional: 10" tablet screenshots (1600 x 2560)
- App icon (512 x 512)
- Feature graphic (1024 x 500)
